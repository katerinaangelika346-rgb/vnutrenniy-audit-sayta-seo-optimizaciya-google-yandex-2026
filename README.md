# 1. Что такое внутренний аудит сайта

Внутренний аудит сайта — это комплексная проверка структуры сайта, контента, технических параметров и внутренних факторов ранжирования.

Цель аудита:

- выявление ошибок оптимизации
- улучшение индексации
- повышение релевантности страниц
- увеличение позиций в поисковой выдаче

# 3. Структура сайта

SEO-структура должна быть логичной и простой.

Пример:

Главная  
→ Категория  
→ Подкатегория  
→ Страница

Правильная структура сайта:

- уменьшает глубину вложенности
- улучшает индексацию
- распределяет ссылочный вес

Подробнее о структуре страниц:  
https://seogidtalk.com/viewtopic.php?t=92

# 4. Оптимизация URL

URL должен быть:

- коротким
- понятным
- содержать ключевые слова

Пример:

site.com/seo-audit-site

Неправильный вариант:

site.com/index.php?id=234123

Подробнее о правильной структуре URL:

# 7. Мета-теги

Основные мета-теги:

Title  
Description  
H1  
H2  
H3

Title должен:

- содержать ключевые слова
- быть до 60 символов

Description:

- до 160 символов
- мотивировать перейти на страницу
